# Contributing

Thank you for contributing to ESQC Mathematics Exercises. Contributions may
include educational prose, exercises, solutions, illustrations, code
snippets, source files, or build tooling.

By submitting a contribution, you represent that you have the right to submit

- source code, standalone code files, fenced code blocks, executable code
  cells, and build tooling are licensed under the MIT License in
  `LICENSE-CODE`; and
- any third-party material is clearly identified with its source, author,
  license, and any other required notices.

You retain copyright in your contribution. By submitting it, you grant the
project maintainers and the public the rights provided by the applicable
license above. Contributions may be edited, combined, redistributed, and
included in HTML, PDF, EPUB, and other rendered editions of the project.

Attribution is recorded in the Git history and `CONTRIBUTORS.md`. If you
require a particular form of attribution, state it when submitting your
contribution and add it to `CONTRIBUTORS.md`.

Do not submit material that you do not have the right to license under these
terms. If a contribution contains material governed by different terms,
identify it before submission so that its compatibility can be reviewed.

## Existing contributions

If material was contributed outside the normal Git workflow, retain a written
confirmation from its contributor substantially in this form:

> I confirm that my contributions to ESQC Mathematics Exercises may be
> distributed under CC BY 4.0 for educational content and under the MIT
> License for code, and that I have the right to grant these permissions.
